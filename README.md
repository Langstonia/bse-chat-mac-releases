# BSE Chat for Mac

The Baltimore Sound Entertainment team chat as a Mac app.

## [⬇ Download BSE Chat for Mac](https://github.com/Langstonia/bse-chat-mac-releases/releases/latest/download/BSE-Chat.dmg)

1. Open **BSE-Chat.dmg** from your Downloads.
2. Drag **BSE Chat** onto **Applications**.
3. Open BSE Chat from Applications and sign in with your BSE email, the same way as the iPhone app.

Works on any Mac with macOS 14 or later, Apple silicon or Intel. It's signed and notarized by Apple, so it opens with a normal double-click.

This page only hosts the download. You need a BSE team account to use the app.
